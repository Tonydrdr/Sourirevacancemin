# Sourire & Vacances — Starter minimal

Ce dépôt est volontairement minimal pour déployer **sans erreurs** sur Vercel.
1) Crée un repo GitHub vide et uploade **le contenu** de ce dossier.
2) Vercel → New Project → Import → Deploy.

- `/` → redirige vers `/bien/villa-bonheur`
- `/bien/villa-bonheur` → fiche démo
- `/pay/[id]` → récap paiement démo (frais 7% min 3€ cap 29€)
- `/api/ok` et `/api/health` → tests
